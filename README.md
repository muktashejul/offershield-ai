# 🛡️ OfferShield AI — Forensic Scam Investigator

An autonomous multi-tool forensic agent engineered to detect recruitment and internship fraud by combining deterministic network validation with structured multimodal cognitive AI.

## Features
- **Deterministic Tools:** DNS MX resolver, WHOIS domain age inspection, and Levenshtein typosquatting detection.
- **Multimodal Ingestion:** Evaluates raw text, multi-page PDFs, and screenshots.
- **Explainable Heatmap:** Color-coded threat highlights identifying upfront fees, brand impersonation, and process skips.
- **Observable Agent Trace:** Step-by-step chronological perception-action log.
- **Legal Redressal:** Generates official grievance drafts for cybercrime.gov.in (IT Act Section 66D) and college placement cell advisories.
